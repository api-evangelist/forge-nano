# Forge Nano

> Forge Nano is a materials-technology manufacturer headquartered in Thornton, Colorado that commercializes particle and wafer Atomic Layer Deposition (ALD) under its Atomic Armor platform and patented ALDx architecture. It coats powders, electrodes and semiconductor wafers at atomic scale to improve energy density, cycle life, thermal stability and yield, selling US-sourced lithium-ion cells from its Morrisville, North Carolina gigafactory, commercial semiconductor wafer-fabrication equipment (including the TEPHRA 200mm cluster tool), and Powder ALD coating systems.

Forge Nano is a hardware and advanced-materials company, not an API provider. As of 2026-08-01 it publishes **no public API, no developer portal, no SDK and no machine-readable API contract** (no OpenAPI, GraphQL, AsyncAPI, MCP server or A2A agent card). See `x-contract-discovery.yml` in this repository for the full record of the discovery probes.
